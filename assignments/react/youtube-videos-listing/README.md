# YouTube Videos Listing

A clean and responsive YouTube-style video listing app built with React and Vite.

The project fetches JavaScript-related videos from the FreeAPI YouTube endpoint and displays them in a modern card-based UI inspired by YouTube.

---

## Features

- Fetches videos using API
- Responsive grid layout
- Modern YouTube-inspired UI
- Pagination support
- Compact view count formatting (`2K`, `1M`, etc.)
- Hover effects and subtle animations
- Clean and minimal design

---

## Tech Stack

- React
- Vite
- JavaScript
- CSS
