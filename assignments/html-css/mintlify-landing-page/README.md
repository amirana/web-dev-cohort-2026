# Mintlify Landing Page (HTML & CSS)

This is a Mintlify landing page project I built as part of the **Web Dev Cohort 2026** assignment.

The goal was to recreate a landing page design using only **HTML and CSS** (desktop only)

**Live Demo:**  
https://amirana.github.io/web-dev-cohort-2026/assignments/html-css/mintlify-landing-page/

---

## What’s in this project

- Built using only HTML + CSS
- Desktop layout (assignment was desktop-focused)
- Sections like navbar, hero, and content blocks
- Used Flexbox/Grid, 
- Font: Inter
- Colors: #08090a, #ffffff, #188b5f
