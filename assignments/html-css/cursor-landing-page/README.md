# Cursor Landing Page (HTML & CSS)

This is a Cursor landing page project I built as part of the **Web Dev Cohort 2026** assignment.

The goal was to recreate a landing page design using only **HTML and CSS** (desktop only)

**Live Demo:**  
https://amirana.github.io/web-dev-cohort-2026/assignments/html-css/cursor-landing-page/

---

## What’s in this project

- Built using only HTML + CSS
- Desktop layout (assignment was desktop-focused)
- Sections like navbar, hero, and content blocks
- Used Flexbox/Grid, 
- Font: Cursor Gothic
- Colors: #14120b, #edecec, #1b1913, #f54e00, #1d1b15
